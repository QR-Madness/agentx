# Installation

How you install AgentX depends on what you want to do with it.

| You want to… | Start here |
|---|---|
| **Use AgentX:** run your own server and chat with your agents | [Quick Start](quickstart.md). It covers the deployment package, its dashboard, and connecting the desktop app or web client. |
| **Run several instances:** staging, a tester's copy, or isolated setups | [Clusters & Gateway](../deployment/clusters.md) |
| **Work on AgentX itself:** build from source with hot reload | [Development Setup](../development/setup.md). On Windows, see [Windows (WSL2) Setup](windows.md) too. |
